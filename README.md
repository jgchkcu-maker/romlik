# romlik

Автоматический агрегатор бесплатных VPN-конфигов.

GitHub Actions каждые 5 минут:
1. скачивает обычные и whitelist-пулы из `sources.json`;
2. удаляет дубли;
3. делает быстрый TCP-prefilter;
4. запускает кандидатов через `xray-core`;
5. выполняет реальный download-тест через локальный SOCKS-туннель;
6. ранжирует рабочие узлы по throughput + latency;
7. публикует TOP-20 в `out/`.

## Файлы
- `out/normal.txt` / `.b64` — лучшие обычные узлы;
- `out/whitelist.txt` / `.b64` — лучшие whitelist-узлы;
- `out/*.json` — метрики скорости/задержки и источники;
- `out/status.json` — последний результат проверки.

Score примерно равен `Mbps * 1000 / (latency_ms + 80)`, поэтому учитываются и пропускная способность, и отклик.

> GitHub cron имеет минимальный интервал 5 минут, но запуск может фактически задерживаться. Скорость измеряется от GitHub-hosted runner, а не от вашего телефона, поэтому это рейтинг качества серверов относительно инфраструктуры GitHub.
